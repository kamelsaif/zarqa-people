# Zarqa People — خطة ريل بعد اكتمال التشغيل

مدة مقترحة: ٥٠–٦٠ ثانية. تصوير رأسي 9:16، مع تكبير الجزء المستخدم من الواجهة. استخدم بيانات العرض الخيالية فقط، وأظهر عبارة «بيانات تجريبية» أثناء المشاهد. لا تصوّر مفاتيح الخدمات أو لوحات الحسابات أو بيانات موظفين حقيقيين.

| الزمن | الصورة | الكلام المقترح |
|---|---|---|
| ٠–٥ ث | طلب إجازة، جدول شفتات، كشف مرتب في قطع سريع | «من أول التعيين لحد كشف المرتب… رحلة الموظف كلها في مكان واحد.» |
| ٥–١٣ ث | الداشبورد ثم دليل الموظفين | «ده Zarqa People: نظام موارد بشرية بالعربي والإنجليزي، من تصميمي وتطويري بمساعدة أدوات الذكاء الاصطناعي.» |
| ١٣–٢٣ ث | الموظف يقدم طلبًا، ثم شاشة المدير يراجعه | «الموظف يقدّم طلبه، والمدير يراجعه، وكل قرار له تاريخ واضح.» |
| ٢٣–٣٣ ث | الشفتات ثم مراجعة تأثيرات الحضور على مسودة المرتب | «الحضور والشفتات داخل نفس الرحلة، وتأثيرها على المرتب بيتراجع قبل الاعتماد.» |
| ٣٣–٤٢ ث | بوابة الموظف ثم طباعة كشف تجريبي | «وكل موظف يوصل لطلباته وكشفه من بوابته.» |
| ٤٢–٥٢ ث | ملفات الكود والاختبارات على GitHub | «والكود موثّق ومتاح على GitHub، عشان اللي حابب يجرّبه أو يطوّره.» |
| ٥٢–٦٠ ث | الشعار ورابط المستودع بعد إنشائه | «إيه أول ميزة تحب تضيفها لنظام زي ده؟» |

## قبل التصوير

- أنشئ مستودع GitHub وانشر المصدر المنقّح، ثم ضع رابطه الفعلي في الوصف. لا تستخدم رابطًا افتراضيًا أو تقول «متاح» قبل التحقق منه.
- صوّر مسارًا واحدًا متصلًا: طلب ← قرار ← سجل. لا تكدّس كل الصفحات في اللقطة.
- استخدم حسابات اختبار مختلفة عند عرض الصلاحيات في النسخة السحابية. تبديل الدور في العرض المحلي محاكاة، وليس اختبار أمان.
- لا تقل إن الاستضافة أو الربط بالخدمات يعملان قبل تنفيذهما وتجربتهما. حاليًا حزمة السحابة معدّة ويظل النشر الفعلي بحاجة إلى إعداد الحسابات والتحقق.
- لو تعرض البريد: صوّر إشعارًا تم تسليمه لحساب اختبار فعلي. البريد يحتوي رابط البوابة؛ لا تقل إن النظام يرفق PDF تلقائيًا.
- لا تدّعِ توفير نسبة وقت أو تكلفة من غير قياس، ولا اعتمادًا قانونيًا أو حساب ضرائب تلقائيًا.

وصف مقترح بعد نشر المستودع: «بنيت Zarqa People: تجربة HR بالعربية والإنجليزية، فيها طلبات وموافقات وشفتات ومراجعة رواتب. المشروع مفتوح المصدر بترخيص MIT. التفاصيل والكود: [ضع رابط GitHub المنشور]. البيانات في الفيديو تجريبية.»
